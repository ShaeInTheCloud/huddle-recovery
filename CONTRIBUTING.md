# Contributing to Huddle Recovery

Thank you for helping kids recover safely. Every kind of help counts.

## Ways to help

- **Athletic trainers, PTs, and physicians:** review the content in `content/` and open an issue with corrections. Clinical accuracy matters more than anything else here.
- **Translators:** review the Spanish content or help add new languages. Add a file next to `content/es.ts`.
- **Parents and athletes:** tell us what was confusing or missing on the worst night. Open an issue in plain words; no code needed.
- **Developers and designers:** pick an issue labeled `good first issue`.

## Ground rules

1. **Never add real athlete data** to the repo, issues, screenshots, or test files. Use made-up examples.
2. **No diagnosis, no clearance.** The app tracks, teaches, and escalates. Features that decide whether someone is injured or ready to play are out of scope unless built with a clinical research partner.
3. **Cite your source** for any health guidance you add or change (CDC, a consensus statement, or a peer-reviewed study).
4. **Plain language.** Write so a 9th grader and a tired parent can follow it at midnight.
5. **Keep it light.** The page should load fast on an older phone with a weak signal.

## Getting started

```bash
npm install
npm run dev
```

Open a pull request with a short description of what changed and why. Content changes need review from someone with clinical credentials before they merge.
